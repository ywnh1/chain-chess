Tauri 与技术栈

这些是连锁棋在性能上做的事，下面两项检测会实测它们在你这台设备上的效果：

  • Tauri 2：Rust 内核 + 系统 WebView，比 Electron 省内存，启动也快
  • Rust 引擎：游戏规则和 AI 全用 Rust 写，编译成原生码；PWA 版编译为 WASM
  • Rayon 多核并行：A-B / PVS 在根节点并行搜索，多核 CPU 都吃得上
  • 搜索剪枝：Alpha-Beta 剪枝、PVS 主变例搜索（Killer / History / 静止搜索）
  • ML 评估：内置 XGBoost 模型（18 维特征），AI 判断更准
  • WebGL 渲染：棋盘用 Canvas 画，动画批量提交，渲染压力交给 GPU

为什么玩连锁棋

你点下的每一颗棋子，都可能引爆整张棋盘。本地热座、人机对战、AI 斗蛐蛐，2~10 人同台。桌面 / Android / 浏览器 PWA 三端都能跑，不用服务器，打开就能开局。

游戏规则

往格子里堆自己的棋子。堆满一格就会炸，炸出去的棋子推着旁边的格子接着炸，最后一个还有棋子的玩家赢。

  1. 下子：点空格放一颗自己的棋子；点自己已经有棋子的格子，再添一颗。别人的格子点不动。
  2. 爆炸：攒够 4 颗就炸，朝上下左右各弹一颗。弹出去的棋子算你的。
  3. 连锁：弹出去的棋子落进旁边的格子，那格要是也堆到 4 颗，跟着炸。一路炸到没格子再够 4 颗为止。
  4. 出局：你在棋盘上的棋子被炸光，就出局了。
  5. 获胜：最后还有棋子留在棋盘上的人赢。
  6. 第一手：不能下在已有棋子周围那 12 格里（上下左右各 2 格，加四个斜角），省得一开局就贴着打。
  7. 第一颗棋子：落下就是“差一颗要爆”的状态，4 级规则下算 3 颗。所以抢地盘那一步常常直接炸开。

第一次玩就选 2 人、7×7、默认边界、4 级，以后想换再换。每项设置后面的「!」会告诉你它影响什么。

AI 介绍

连锁棋有 三种 AI，思路分两类：按人工规则下、搜索推演。本地对战、AI 对战、AI 斗蛐蛐里都能随便换。三种都用 Rust 引擎实现，桌面端 A-B/PVS 走 Rayon 多核并行，PWA 版是单线程 WASM。

策略算法 · 启发式规则

不做搜索，按人工排好的优先级直接出招，所以最快，新手和低配设备都用得上。

三级优先 → 优先走即将爆裂的棋子（count=3）
安全升级 → 避开对手三级附近的二级棋子
渐进控制 → 一进二、下三级，逐步扩大地盘

Alpha-Beta 剪枝 · 经典搜索

标准的 Alpha-Beta 剪枝，Rust + Rayon 在根节点并行。走法是复制棋盘而不是撤销，多玩家连锁反应下反而更省事。

搜索深度 1~10 层 · 根级分支 top 10 · 走法排序 三级优先
随机化探索 早期对局加入随机扰动，增加走法多样性
评估函数 支持增强版（位置+威胁评分）或手写规则评估

PVS NegaMax · 精炼剪枝

Principal Variation Search（主变例搜索）：先假定最优走法排在第一，后面的走法用零窗口（Null Window）快试一下，要么马上证明它不如第一位，要么重搜。360 局两两对战里（ML 评估 · 深度 2 · 含异形棋盘），PVS 拿到 60.0%，A-B 是 75.6%；规则棋盘上两者接近，形状越不规则，PVS 的剪枝越容易误判，详见「AI 性能评测」。

Killer 启发 每层记录两条杀招走法 · History 启发 全局走法成功率表
QSearch 静止搜索 到底层只搜索爆炸性走法（限3层），消除水平线效应
动态分支 浅层多搜深层少搜 · 根级 Rayon 并行 多核加速

早期版本还有一档 MCTS（蒙特卡洛树搜索），评测里长期只有 13% 左右的胜率，明显低于其他三种，已在游戏内移除，也不再参与默认评测。

教学

两块内容：先看游戏怎么玩，再看局域网联机怎么连。每节点标题展开。

游戏规则

一句话

往格子里堆自己的棋子。堆满一格就炸，炸出去的点把邻居染成自己的、各加一个点，连锁到停为止，最后还有棋子的人赢。

怎么下

  1. 点一下，多一个点：点空格，长出一颗自己的棋子（1 个点）；点自己已经有棋子的格子，加 1 个点。别人的格子点不动。
  2. 3 个点是临界：默认 4 个点爆炸，所以一颗 3 点的棋子，再点一下就炸。
  3. 爆炸往四个方向各送一个点：上下左右各一份，自己这一格清空、变成空格。
  4. 送到空格：长出一颗你的棋子，带 1 个点。
  5. 送到对方棋子：那颗棋子变成你的，点数加 1。
  6. 连锁：如果对方的棋子原来是 3 点，被你同化后加 1 点正好到 4 点 —— 它也炸，再往四个方向送点，就这样一路传下去，直到没有格子再够 4 点。

爆过一轮之后，棋盘上剩下的棋子就是各家的家底。谁的点被全部同化光，谁出局；最后还有棋子的人获胜。

爆炸阈值默认 4 点，也可以选 3 点（速爆）或 5 点（重炮）。阈值是 N 时，「N−1 点」就是临界：再点一下、或者被炸到加 1 点，都会引爆。下面讲策略时都按默认的 4 点说，也就是 3 点是临界。

基础策略

核心只有一句：让场上大部分棋子停在 2 点或 3 点。1 点是没成型的，4 点是已经炸没的，2 和 3 才是能用的力量。

3 点用来压制对方的 2 点

  • 对方的 2 点想发展，得先升到 3 点、再升到 4 点才炸。可它旁边要是贴着你的 3 点，他一旦把 2 点升成 3 点，两颗 3 点就顶在一起了 —— 这时谁再动一下，都是一起引爆。
  • 于是他不敢轻易点，扩散就卡在这儿。你的 3 点只要贴住他的 2 点，就是一根引信。

对方的 3 点连上你的 3 点，就点自己那颗

  • 这是最赚的一手：点自己的 3 点 → 自己炸 → 对方的 3 点被同化，加 1 点变成 4 点 → 对方那颗也跟着炸 → 连锁继续往下传。
  • 等于用自己一颗引爆，把对方整片带下水。连得越长越值。

2 点当防线

  • 对方炸过来，你的 2 点只会被同化成他的 3 点，加 1 点还不到 4 点，不会立刻再炸 —— 他的连锁在你这里断掉，这一轮攻势就被吃掉了。
  • 而那颗刚变成 3 点的棋子，现在是临界状态，谁碰都可能引爆。它看着是对方的战果，其实是个随时会炸的靶子，下一手就能针对它做文章。

总原则

  • 别把自己的棋子堆到 4 点就完事 —— 除非这一炸是算好的连锁起点。
  • 别把 1 点、2 点堆在对方 3 点的旁边，那等于把引信递过去。
  • 反过来，看到对方的 3 点旁边有自己的 3 点，那就是你的机会。

开局界面

点首页的「开始游戏」进入。每一行右侧都有「!」按钮，点开就是这一项的说明。

棋盘形状：正方形是 5×5 到 19×19；也可以选长方形（长宽各 5–19），或者用形状编辑器自己点出一个不规则棋盘（十字、口字、L、U 之类）。挖掉的格子是「洞」。异形棋盘同样支持全部边界：默认边界下棋子飞进洞会消失；回环会绕过洞落到下一格；反弹把撞到洞的能量弹回对面；降级按形状轮廓算边缘和拐角。

我创建的自定义棋盘：画好的形状可以起名保存，出现在「自定义」下面的列表里，最多 30 块。点一块即可切换使用，「编辑当前」改它，「删除」移除它，「新建」从当前棋盘继续画。 编辑器里按住格子滑动能连续涂上或擦掉，按下的第一格决定这一笔是涂还是擦。

  • 5×5 ~ 7×7：几步就进连爆，节奏快，新手选 7×7
  • 9×9 ~ 13×13：攻守都比较从容，适合用来练
  • 15×15 以上：一局能打很久，考验耐心

棋盘越大，同一局能容纳的玩家越多；选了小盘，人数上限会自动收缩。

玩家数：2 ~ 10 人，上限看可用格数（少于 25 格 5 人、少于 36 格 7 人、其余 10 人）。

边界模式：棋子炸到棋盘边上时怎么算。

  • 默认：弹到棋盘之外就消失（最简单，建议先用这个）
  • 回环：从左边界出去、从右边界出来，上下同理，棋盘相当于一张卷起来的纸
  • 反弹：弹到边界后弹回场内
  • 降级：中央 4 颗才爆，形状边缘 3 颗、拐角 2 颗就爆 —— 越靠边越危险（只与 4 级阈值搭配）
  • 随机：开局随机定下一种，整局不再变

爆炸阈值：攒够几颗才炸。

  • 3 级：最易连锁，引爆频繁
  • 4 级：默认，平衡
  • 5 级：攒得慢，节奏慢，更难预测
  • 随机：开局随机定下 3 / 4 / 5 之一，整局不变（只会抽到与当前边界兼容的阈值）

玩家配置：点玩家卡片逐个设置。

  • 类型：人类 / AI。全人类 = 本地对战，混合 = 人机对打，全 AI = 斗蛐蛐（纯观战）
  • 名称：棋盘和统计里显示的名字
  • 算法（AI）：策略（快、适合新手） / Alpha-Beta（最强） / PVS（A-B 的加速版）
  • 搜索深度（AI）：1~10 层。越深思越强，但思考时间也越长；选太深会等很久
  • 随机刻度（AI）：0%~30%。越高走法越不可预测，越低越“照着最优解走”
  • 评估函数（AI）：ML 模型（默认，训练出来的打分） / 手写规则（轻量，设备弱时更流畅）

不想逐项配就用默认值：7×7、2 人、默认边界、4 级，直接开始。

对局中

页面顶部那一排按钮，从左到右：

  • 悔棋：撤回上一步。AI 思考中或动画播放中不能悔
  • 暂停：中断并自动存档，随时可以继续
  • 跳过：自动跳过连锁爆炸的动画，直接看结果
  • ⚡ 一键终局：场上只剩 AI 时出现，直接算出最终结果，不用干等
  • 💡 建议：让 AI 给出当前这一步的推荐落点，不替你做决定

玩家栏（棋盘上方）的彩色标签就是各位玩家：亮着的是当前回合，变暗的是已出局，标签上的数字是棋子数。末尾会显示当前进行到第几步。

长连爆中点「跳过动画」可以一键看完；开启「跳过」之后都自动跳过。

历史记录

回放与详情：点任意一条记录，可以看到对局详情与图表（棋子数 / 点数双折线）。回放支持 0.5x / 1x / 2x / 4x 倍速。

多选：两种进入方式 ——

  • 点条目左侧的选择框
  • 长按条目约半秒（手机、桌面都支持）

进入多选后，底部会出现操作栏：反选、导出选中、删除选中、取消。逐项点选即可增减。

反选会把当前列表里没选中的全选上、已选中的取消。它只作用于搜索/筛选后看得见的那几条，被筛掉的记录不受影响。

搜索与筛选：列表上方的搜索框可以按玩家名、AI 算法名、模式名查找（不区分空格）；下面一排是模式筛选：全部 / 本地 / AI 对战 / 斗蛐蛐。

战绩汇总：列表顶部的几行小字是跨对局的统计 —— 总对局数、已完成局数、历史最长连锁、各模式的局数分布。

局域网联机

这是个什么功能

同一个 Wi-Fi 或手机热点下的几台设备，直接连起来打一局。不经过互联网，也没有服务器：房主的手机/电脑自己开一个端口，其他人连上去。只有桌面版和 Android 版有，浏览器 PWA 没有（网页不能监听端口）。

支持 2~10 人。棋步只在房间里那几台设备之间传，流量很小。

第一步：所有人连同一个网络

最简单的是开一台手机的热点，其他人连这个热点。用家里的路由器也行，但要确认大家连的是同一个 Wi-Fi（2.4G 和 5G 常被拆成两个不同的网，连岔了就互相看不见）。

不用连互联网也能玩：没有外网、只开热点照样能联机。

第二步：一个人创建房间

  1. 首页点「局域网联机」
  2. 填个昵称（最多 12 个字）
  3. 选棋盘大小（房主定，整局不变）
  4. 点「创建房间」

房间地址会显示成 192.168.x.x:端口，这就是其他人要连的东西。念给旁边的人，或者自己念给自己听——地址只在局域网内有效，出了这个网络就没人能连。

第三步：其他人加入

两条路，任选：

  • 直接输地址：把房主念的那串 192.168.x.x:端口 填进输入框，点「加入」
  • 搜索附近房间：点「搜索附近房间」，等一两秒，列表里出现房间后点一下就连上

搜不到就先手输地址——有些路由器会拦局域网广播，但直连一般不受影响。

第四步：准备，然后开局

加入的人点「准备」，房主那边会看到「已准备」。等所有人都准备好了，房主点「开始游戏」，大家同时进入棋盘。

房主自己在开局前不能准备/取消——他本来就是发起人。

对局中

  • 轮到谁，谁的格子才能点；不是你的回合点了会提示「等待其他玩家落子」
  • 不能暂停、不能悔棋：一暂停就挡住别人落子，一悔棋两边的棋盘就对不上了。所以对局中右上角的「暂停」变成了「退出」
  • 谁掉线或者退出，这局就结束（房主的连接是唯一的转发点，他走了所有人都断）
  • 打完可以在结算页看排名和图表，对局也会进历史记录，模式标成「局域网」

连不上？按顺序排查

  1. 两台设备真的在同一个网吗：看各自 Wi-Fi 详情里的 IP，前三段要一样（比如都是 192.168.1.x）。2.4G / 5G 分开的路由器最容易在这翻车
  2. 地址抄对了吗：IP 加冒号加端口（192.168.1.23:41234），少个冒号或者端口写错就连不上
  3. 房主那边地址显示 127.0.0.1：说明房主本机没拿到局域网地址（Wi-Fi 没连上或只有移动数据），换到真正的 Wi-Fi 上再建一次
  4. 路由器开了「AP 隔离 / 客户机隔离」：这个选项会让设备之间互相看不见，得在路由器后台关掉
  5. 系统防火墙：Windows 第一次建房间可能弹窗问要不要允许，要选「允许专用网络」
  6. Android 提示没有本地网络权限：在系统设置里给连锁棋放开局域网/本地网络权限（部分系统的「附近设备」权限也管这个）

还是不行？

把这几项一起发过来：两台设备各自的 IP、房主界面显示的地址、有没有弹错误提示、手机/电脑型号。可以直接到「关于 → 联系作者」反馈，或者点下面的按钮。

反馈入口：更多 → 关于连锁棋 → 联系作者。

第三方 SDK 与服务

数据放在哪

连锁棋没有账号系统，也不需要登录。棋盘、走法、对局记录全部保存在你自己的设备上，不会上传到任何服务器。应用只在检查版本更新时访问网络。

会联网的第三方服务

  • Gitee 仓库接口更新检查接口地址 gitee.com/api/v5/repos/ywnh1/chain-chess-release/contents/update.json · 启动时静默请求一次，或在更多里点「检查更新」时请求。只读取公开仓库里的版本号文件，用来判断有没有新版本；不发送账号、设备标识或游戏数据（请求本身的 IP 与 User-Agent 由 HTTP 协议附带，代码未额外附加任何信息）。

除了这个域名，应用不会主动请求别的地方。

局域网联机

局域网联机只在同一 Wi-Fi / 热点内直接建连：房主在本机监听一个端口，其他人输入地址或通过局域网广播找到房间。棋步只在你和房间内玩家的设备之间传输，不经过互联网，也不发往任何第三方服务器。离开房间或退出应用即断开。

统计 SDK 只在网页版 PWA

Windows / Linux / Android 应用不加载任何统计 / 分析 SDK，页面里没有第三方脚本。访问量统计（51.la 站点统计）只存在于网页版 PWA，由网页在浏览器中加载；它与本应用无关，也不会收到本应用的任何数据。

系统能力（Tauri 插件）

  • tauri-plugin-dialog本地导出历史记录时弹出系统的「保存文件」对话框。
  • tauri-plugin-fs本地把导出的历史记录 JSON 写入你选定的位置，启动时读取本机历史记录文件。
  • tauri-plugin-opener本地用系统默认方式打开下载页面或已下载的安装文件。

三个插件都只在本地工作，不联网，也不会在你没操作的时候读写文件。

本应用不包含

无广告 SDK、无统计 / 分析 SDK（网页版 PWA 的 51.la 统计不在本应用中加载）、无账号 / 登录 / 支付 SDK、无崩溃上报 SDK、无社交分享 SDK、无用户画像或行为分析 SDK。

不想被统计怎么办

本应用不含统计 SDK，不需要做任何处理。网页版 PWA 可以用浏览器的隐私扩展或广告拦截规则屏蔽 sdk.51.la 域名，屏蔽后所有游戏功能照常可用；彻底断开网络也能正常游玩（只有「检查更新」会失败）。

开源库的许可证清单见「关于 → 许可证」页，完整源码以 MIT 协议公开在 GitHub。
