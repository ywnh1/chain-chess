你点下的每一颗棋子，都可能引爆整张棋盘。

**连锁棋** 是基于 Chain Reaction / 爆裂棋玩法改进的多人策略游戏。2~10 人对战，棋子攒满格子就炸——炸出的棋子触发下一轮连锁，直到只剩一人存活。

纯客户端应用（Tauri + Rust），无需服务器，本地启动即玩。

---

## 🎮 游戏规则

- **落子** — 点击空位落子（首步需避开已有棋子周围 12 格），点击自己的棋子加子
- **爆裂** — 格子中棋子数达到 4 时，向上下左右各扩散一个棋子
- **连锁** — 爆裂扩散会触发相邻格子的连锁爆裂，形成连爆效应
- **淘汰** — 某玩家的所有棋子被吞噬时，该玩家被淘汰
- **胜利** — 最后存活的一位玩家获胜

## ✨ 功能一览

### 游戏模式

- **👥 本地对战** — 2~10 人在同一设备轮流落子，每人可自定义名称
- **🤖 AI 对战（PVE）** — 1 名人类 + 1~9 个 AI 对手，每位 AI 独立配置算法、搜索深度和随机刻度
- **⚔️ AI 斗蛐蛐** — 2~10 个 AI 对战，纯观赏，每个 AI 独立配置

### 游戏设置

- **棋盘大小** — 5×5 到 19×19 自由选择
- **玩家配置** — 弹窗设置每位玩家的类型（人类/各类 AI）、名称、算法、搜索深度、随机刻度和评估函数（ML / 手写）
- **随机刻度** — 0%~30% 可调，游戏开始固定 40% 逐渐降至设定值

### AI 引擎

- **四种算法** — 策略（启发式规则）、Alpha-Beta 剪枝、PVS NegaMax、MCTS 蒙特卡洛树搜索
- **Rust + Rayon** — 均用 Rust 实现，Rayon 多核并行，深度 1~10 层可配置

### 用户界面

- **液态玻璃主题** — 深色虹彩渐变玻璃 UI，10 个彩色光球缓慢浮动
- **响应式布局** — 平板横屏 / 手机竖屏自适应
- **挖孔屏适配** — `safe-area-inset-top` 适配刘海屏和挖孔屏
- **路由管理** — 统一 Router 页面管理，生命周期钩子，智能回退导航

### 数据与统计

- **结算图表** — 游戏结束后展示双折线图（棋子数 / 点数变化），支持预览全屏缩放
- **历史记录** — 自动保存对局记录，可回看统计图表
- **中断恢复** — 异常退出或手动暂停时自动保存未完成对局，历史页面一键继续
- **内存+磁盘两层存储** — 超过 500 步自动溢出到磁盘，防止内存暴涨

### 音效与反馈

- **合成音效** — 落子、爆炸、淘汰、获胜每种事件都有独立音频反馈（Web Audio API）
- **震动反馈** — Android 原生支持，桌面静默降级
- **连锁动画跳过** — 长连爆可一键跳过，提升体验

## 🤖 AI 引擎详解

连锁棋内置四款 AI 算法，覆盖三大搜索范式：**启发式规则**、**树搜索剪枝** 和 **随机模拟**。

### ⚡ 策略算法 — 启发式规则

纯 JavaScript 引擎，基于人工优先级规则快速决策。无需 Rust 引擎，响应最快，适合新手入门和低算力设备。

- **三级优先** — 优先走即将爆裂的棋子（count=3），触发连锁反应
- **安全升级** — 避开对手三级棋子附近的二级棋子，防止被吞噬
- **渐进控制** — 一进二、下三级，逐步扩大地盘
- **首子中心** — 第一手落在棋盘中央附近

### 🧠 Alpha-Beta 剪枝

标准 Alpha-Beta 剪枝搜索，Rust + Rayon 多核并行。采用克隆式搜索（每次走法复制棋盘而非撤销），天然适配多玩家连锁反应。

- **Rayon 多线程** — 根节点走法并行搜索，充分利用多核 CPU
- **走法排序** — 三级棋子优先、周围对手多优先，提高剪枝效率
- **根级分支** — 根级 top 10 走法，内部节点无分支限制（全量搜索）
- **深度可调** — 支持 1~10 层搜索（默认 2）
- **随机化探索** — 早期对局加入随机扰动，增加走法多样性

### 🔬 PVS NegaMax — 精炼剪枝

Principal Variation Search（主变例搜索）是 Alpha-Beta 的精炼版本。核心思想：假设第一个搜索的走法就是最优的，后续走法用零窗口（Null Window）试探，快速证明或证伪，大幅减少搜索量。

**增强特性：**

- **Killer 启发** — 每层记录两条杀招走法，后续优先尝试
- **History 启发** — 40×40 全局历史表，记录各位置的成功率
- **QSearch 静止搜索** — 搜索到底时只搜爆炸性走法（限 3 层），防止水平线效应
- **动态分支控制** — 浅层多搜（depth=1→14 条），深层少搜（depth=3→8 条）
- **根级 Rayon 并行** — 多核并行加速根层搜索

560 局基准测试中，PVS d=2 ML 以 70.0% 胜率持平 Alpha-Beta d=2 ML（70.7%），手写评估下 PVS（49.3%）反超 AB 手写（35.0%）。

### 🎲 MCTS 蒙特卡洛树搜索

与剪枝搜索截然不同的范式——不依赖任何评估函数，通过大量随机模拟评估走法优劣。

```
SELECT → EXPAND → PLAYOUT → BACKPROPAGATE
```

- **UCB1** 平衡探索与利用
- **策略偏置 Playout** — 80% 概率选评分前 3 的走法，20% 纯随机
- **渐进展开** — 子节点访问 ≥3 次后才展新分支
- **迭代数** — depth=1~10 对应 1200~12000 次迭代，树节点上限 3000

擅长发现 Alpha-Beta 不易察觉的非直觉走法。

### 🤖 评估函数

Alpha-Beta 和 PVS 搜索可使用两种评估函数：

- **增强版评估**（默认）— 在原手写规则基础上加入位置权重、邻居威胁评分和爆发势能评估，棋力更强
- **手写规则** — 经典启发式评估，稳定可靠

两种评估函数可在玩家配置弹窗中随时切换，无需重启游戏。

- **深色液态玻璃主题** — 虹彩渐变玻璃卡片，`backdrop-filter: 32px` 毛玻璃效果，内斜面采光高光

## 🔧 技术架构

```
┌──────────────────┐     ┌──────────────────┐
│  Web 前端（JS）   │     │  Rust 引擎        │
│                  │     │                  │
│  ┌─ UI 渲染 ──┐  │     │  ┌─ AI 搜索 ──┐  │
│  │ 棋盘/弹窗/   │  │     │  │A-B/PVS/MCTS│  │
│  │ 图表/路由    │  │     │  └───────────┘  │
│  └────────────┘  │     │  ┌─ 评估函数 ─┐   │
│  ┌─ 音效 ────┐  │◄────►│  │增强/手写   │   │
│  │Web Audio   │  │invoke│  └───────────┘  │
│  └────────────┘  │     │  ┌─ 游戏逻辑 ─┐  │
│  ┌─ 存储 ────┐  │     │  │落子/连锁/   │  │
│  │Tauri FS    │  │     │  │淘汰判定     │  │
│  └────────────┘  │     │  └───────────┘  │
└──────────────────┘     └──────────────────┘
```

- **前端**：原生 JavaScript + CSS，零框架依赖
- **后端**：Rust（lib.rs + 搜索算法）+ Tauri v2 桥接
- **AI 引擎**：Alpha-Beta 使用 `alpha_beta_pruning` crate，PVS 和 MCTS 自实现
- **并行计算**：Rayon `par_iter()` 多核并行搜索
- **评估函数**：增强版手写评估（位置权重 + 威胁评分）或 XGBoost 模型（可扩展）
- **存储**：JSON 文件（`history.json`、`round_data.json`、`saved_game.json`）
